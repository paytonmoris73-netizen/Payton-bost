# Real photos

Drop real photographs here and they replace the placeholder covers automatically. No code changes needed.

- Recipes: name the file after the recipe id, e.g. `r2.jpg`, `r3.webp` (ids are in `src/data.ts`).
- Ingredients: name the file after the ingredient id, e.g. `pistachios.jpg` (slug of the name).
- Formats: jpg, jpeg, png, webp. Aim for about 1600px on the long edge, under 400 KB.
- Only add photos you took or have a licence to use. Record the source and licence in `credits.json`
  (`{ "r2.jpg": { "by": "Name", "license": "CC BY 4.0", "url": "https://..." } }`); credits are shown on the recipe page.
